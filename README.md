# Платформа анализа рыночных ставок БВУ РК по залоговым кредитам МСБ

Реализация MVP по [ТЗ](PRD.md) — раздел 9, этап **MVP**:
- список банков и базовая сравнительная таблица;
- ручной ввод/верификация условий по банкам (парсинг — следующий этап, F1);
- история изменения ставок с фиксацией даты (раздел 7 ТЗ);
- разграничение ролей: администратор/оператор, начальник управления, директор департамента (раздел 4 ТЗ).

Автоматический парсинг сайтов банков (F1), модуль автоматического анализа
преимуществ/недостатков (F3) и выгрузка отчётов (F6) запланированы на
следующие этапы (см. раздел 9 ТЗ) и в этой версии не реализованы.

## Структура

```
backend/   — FastAPI + SQLAlchemy (SQLite по умолчанию, легко переключить на PostgreSQL)
frontend/  — React (Vite) — дашборд, карточка банка, админ-панель
PRD.md     — исходное техническое задание
```

## Запуск backend

```bash
cd backend
python -m venv venv
venv/Scripts/activate        # Windows
pip install -r requirements.txt
python -m app.seed           # создаёт пользователей и список банков
uvicorn app.main:app --reload
```

API будет доступен на `http://localhost:8000`, документация — на
`http://localhost:8000/docs`.

### Учётные записи по умолчанию (созданные seed-скриптом)

| Логин | Пароль | Роль |
|---|---|---|
| admin | admin123 | Администратор/оператор данных |
| head | head123 | Начальник управления |
| director | director123 | Директор департамента |

**Обязательно смените пароли** перед реальным использованием — они заданы
только для локальной разработки.

### Переход на PostgreSQL

Задайте переменную окружения (или `.env` в папке `backend`):

```
DATABASE_URL=postgresql+psycopg2://user:password@localhost:5432/rates_db
```

и установите драйвер `psycopg2-binary`.

## Запуск frontend

```bash
cd frontend
npm install
npm run dev
```

Приложение будет доступно на `http://localhost:5173` и обращается к backend
через прокси `/api` (настроено в `vite.config.js`).

## Что сделано в MVP

- Модель данных под все параметры сравнения из раздела 5.4 ТЗ.
- Сравнительная таблица с сортировкой и фильтрацией по ставке, сумме, сроку.
- Карточка банка с детальными условиями и графиком динамики ставки.
- Индикатор устаревших данных (порог — раздел 7 ТЗ, настраивается в
  `backend/app/config.py`).
- Админ-панель: управление списком банков и ручной ввод/верификация условий
  (каждое сохранение фиксируется в истории ставок).
- Ролевой доступ по логину/паролю (без SSO — раздел 5 ТЗ).

## Важно про данные

Список банков в seed-скрипте (`backend/app/seed.py`) содержит только
названия крупнейших БВУ РК — ссылки на страницы условий и сами условия
кредитования **не включены**, их нужно собрать и сверить с официальными
сайтами банков через админ-панель (это отдельная задача из объёма проекта,
см. раздел 5.3 и F5 ТЗ). Финансовые показатели (ставки, суммы, LTV и т.д.)
не должны публиковаться без проверки оператором.
